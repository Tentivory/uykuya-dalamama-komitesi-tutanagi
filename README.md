## Ne işe yarar?

Hiçbir işe yaramaz. Yine de çalışır.

`komite.py` çalıştığında:
1. Sana resmi bir uykusuzluk tutanağı basar.
2. Rastgele bir “karar maddesi” üretir (kediler, asansör, çay, balkon).
3. İmza kuyruğunu simüle eder.
4. En sonda damga basar. Damga gerçek değildir. His gerçektir.

## Kurulum

```bash
python3 komite.py
```

Python 3 yeter. Bağımlılık yok. Uyku da yok.

## Kullanım örneği

```bash
python3 komite.py --isim "Ayşe" --dakika 187
```
